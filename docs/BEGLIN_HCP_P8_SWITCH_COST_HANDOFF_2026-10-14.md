# Beglin HCP P8 — 전환 비용 분해·보수적 전환 억제기

작성: 2026-10-14 / Asia/Seoul. 기존 P6 증거 재분석과 신규 소스·단위 검증이다. 새로운 모델 추론이나 운영 배포가 아니다.

## 판정

전환 억제기, 기존 비용 계층의 분해, 전환 내부 9개 구간 계측 삽입기를 구현했다. EOE에서 Python 회귀 48/48 PASS, `QWEN_GPU_MLX`를 켠 Clang C 문법 검사 exit 0이다. 계측 삽입을 역변환하면 검증된 P5 CB128 C 소스와 정확히 일치한다.

**실질적인 가속은 여전히 미입증이다.** XOX의 저장공간 게이트가 새 네이티브 실행을 차단했으므로, 동기화·스냅샷·재포장·ACK 각각의 실제 시간과 고정 AF/A/B 대비 새 후보의 실기기 성능은 측정하지 않았다.

## 기존 실측 288회에 대한 비용 분해

원본 speed.json의 SHA와 6블록 × 12입력 × A/B × 전환/유지 288개 셀, 중복·누락, 출력 SHA를 재검증했다. 아래는 A/B를 동일 비중으로 합친 평균이다.

| 비용 경계 | 전환 요청 평균(ms) | 유지 요청 평균(ms) |
|---|---:|---:|
| ACK 기록 이전 네이티브 전환 | 330.462486 | 0 |
| 나머지 네이티브 구간(ACK 포함) | 523.632833 | 538.202264 |
| 워커 IPC·폴링 | 14.937715 | 15.595492 |
| Python 정책 호출 래퍼 | 3.148376 | 2.817417 |
| 전체 Python admission | 872.181410 | 556.615172 |

차분 정의는 transition, engine−transition, roundtrip−engine, admission−roundtrip이다. 모든 셀에서 합계가 전체 admission과 맞는다. HTTP/원격 네트워크 왕복은 아니다. ACK는 나머지 네이티브 구간에 섞여 있으므로 현재 자료만으로 ACK 시간을 별도 산출하지 않는다.

## 소스에서 확인한 두 가지

`qwen_infer.c`의 `moe_gpu_txn_mark_terminal()`은 `moe_gpu_transition_finish()` 다음에 `moe_gpu_write_applied_ack()`를 호출한다. 따라서 기존 transition_wall_ms에는 내구성 ACK 기록이 포함되지 않는다.

`moe_gpu_rebind_set_apply_quiescent()`는 qNg64 CPU 캐시에서 텐서를 얻은 뒤 `mlx_gpu_bind_af()`를 호출한다. 현재 `mlx_moe.cpp`의 5·6비트 바인딩 경로에는 새 재포장 버퍼 할당과 비트 루프가 있다. CPU qNg64 캐시 적중이 MLX 재포장 비용까지 제거한다는 뜻은 아니다. 이 경로는 병목 후보이며, 330ms의 대부분이라고 실측한 것은 아니다. MLX 재포장 캐시 최적화 자체도 이번에 구현하지 않았다.

## 전환 억제기 계약

`hcp_p8_governor.py`는 순수 결정 모듈이다. 파일·네트워크·모델 호출이나 운영 권한 부여를 하지 않는다. 실행 어댑터는 기존 정밀도 스케줄러와 `gpu_runtime_control.verify_terminal_ack`를 그대로 사용해야 한다.

독립적으로 허용된 정책 집합, 같은 워커·문맥·정책의 근거, 유효한 비용 예측, 양수인 이득 신뢰구간 하한을 요구한다. 예측 기간의 이득 하한이 전환 비용 상한과 제어 비용의 합을 넘지 않으면 유지한다. 실험 기본값은 최소 유지 8회, 64회 창의 최대 전환 4회다. 이 값은 튜닝된 최적값이나 품질 인증값이 아니다.

계획·발행·완료를 구분한다. 실제 ACK의 정책·epoch·워커·문맥·txn_id가 확인되기 전에는 상태를 갱신하지 않는다. 중복 발행과 결과 불명 타임아웃 이후 abort/retry를 차단한다. 테스트의 ACK fixture 및 `verified_by_native_controller` 플래그는 실제 네이티브 증거나 암호학적 권한 인증이 아니다.

현재 근거에서는 B 품질 권한이 없으므로 KEEP이다. 비용 조건만 별도로 보아도 유지 요청 B−A 95% 구간 [-10.738703, +5.762349]ms 때문에 이득 하한이 양수가 아니다. 유효한 손익분기 유지 횟수는 미확정이다. 관측 전환 최대 412.927ms는 과거 관측값이지 미래 비용 보증이 아니다.

## 기존 셀 조회 방식의 모의 재생 — 새 속도 실측 아님

P6의 고정된 72개 입력 순서에 A/B가 교대로 제안되는 인위적인 스트레스 조건을 붙였다. 아래 시간은 해당 블록·입력·정책·전환 여부의 기존 관측값을 조회해 합산한 추정치다. 새 모델 실행·학습된 예측기·미사용 holdout·인과적 가속 증거가 아니다. 초기 정책 설정과 warmup은 포함하지 않았다.
