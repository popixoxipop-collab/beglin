# BEGLIN Q — 커널 인식 국소 정밀도 할당기 구현·실측 핸드오프 (2026-10-22)

**연구 브랜치:** `research/oml-acs-prereg-20261021`  
**모델/실기기:** Qwen2.5-1.5B-Instruct, Apple Silicon EOE, native BEGLIN C CPU 28 decoder layers.  
**판정:** **비트폭·커널·메모리·추론 시간을 함께 고려하는 오프라인 할당기 구현/전체 모델 실행 PASS. 모델 출력 품질 우월성 FAIL(개발 관찰) / 최종 Q 가설 NO_VERDICT.** `main`, 운영 BEGLIN, Tailnet immutable 릴리스, 원본 체크포인트는 변경하지 않았다.

## 구현

- 원본 BF16 모델 가중치에서 뽑은 196개 투영 텐서의 **실제 qNg64 8비트 / Q4G64 4비트 양자화 결과**를 재사용했다. 7개 역할 × 28계층.
- 7개 역할의 실제 native 커널 지연을 Apple EOE CPU에서 추가 측정했다. 4비트는 BEGLIN Q4G64 **NEON fused 1/6 스레드** 중 빠른 것을 선택하고, 8비트는 이전 단계에서 실제 수치/배치 일치 검증을 끝낸 **qNg64 n8 1회 재배열 NEON**을 사용한다. bitplane n8와 별도 Q4G64는 혼동하지 않는다.
- 텐서 (i)의 정밀도·커널 (m)에 대해 **메모리 (M_{im})**, **연산 비용 (T_{im})**, **가중치 오차 대리지표 (E_{im})** 를 기록한다. 8비트가 4비트 대비 얼마나 원본 가중치 상대 L2 제곱오차를 줄이는지가 현재 목적함수다.
- 각 역할 내에서는 텐서 형태/커널 비용이 동일하므로 상위 (k)개의 오차 감소 텐서를 택하는 것이 해당 역할의 목적함수에 대해 정확하다. 7개 역할의 정수 승격 개수 ((k_1,dots,k_7))를 **합계 28개**가 되도록 전수 탐색하고, 정확한 압축 바이트 예산과 실측 커널 지연에 기초한 예측 지연 한도를 만족하는 정책 중 **오차 감소 합계 최대**를 선택한다. 무작위 휴리스틱이 아니라 **정의된 대리 목적함수에 대해서만 정확한 전수 최적해**다.
- 측정한 역할별 커널 시간을 단순 합산하는 것은 전체 모델 지연에 대한 근사이므로, 기존 전체 4비트 실측 75.26ms와 이전 역할 균등 혼합 116.18ms로 배율 `gamma=1.0394064`을 맞췄다. 이 보정은 새 정책 모델 점수를 보기 전에 완료했다. 실제 지연을 보증하지는 않는다.

- 반면 공개 합성 21개 예측 위치에 대한 PPL은 전체 Q4(4649.3)보다 새 정책(4568.9)이 소폭 낮았으나, 무작위 혼합(3411.2)보다 크게 나빴다. 따라서 로짓 KL와 PPL의 서로 다른 지표를 섞어서 품질 향상으로 주장하지 않는다.

## 범위와 이어질 연구

**현재 구현은 Apple CPU에서의 하드웨어/커널 인식 오프라인 정밀도 할당기다.** 실시간 입력마다 비트를 옮기는 알고리즘, 기존 BEGLIN 운영 엔진 자동 승격, CPU/GPU 통합 allocator, 품질 민감도에 기반한 비트 할당으로 오해해서는 안 된다. 현재 3·5·6·7비트는 원본 엔진 포맷이 있더라도 이번 실측 커널 후보군에서는 제외했다.

앞으로의 필수 개선은 가중치 오차가 아니라 모델 행동에 영향을 미치는 **품질 민감도 대리 변수**를 별도 허용된 데이터에서 추정하고, 정밀도별 커널 지연 및 정량 품질 손실을 함께 최적화하는 것이다. 이전에 차단된 단일 텐서별 출력 민감도 실행은 우회·재시도하지 않았다.

동일 하드웨어에서도 지속 처리량·부하·Apple Metal·에너지·KV-cache·배치 크기별 dispatch, 실제 3모델 평가, 기존 V6 사용 24개 문항 provenance 감사를 추가하지 않으면 최종 연구 가설을 수용할 수 없다. 연구 scratch는 사적인 `0700` 경로이며 실험 Qwen C의 최초 출력 파일 `0644`를 발견해 `0600`으로 제한했다. 향후 단독 실험 실행 래퍼에 `umask(0077)`을 강제해야 한다.

**`main`, 운영 릴리스 `g6-0.9.0-operator.900387`, 원본 HF 모델·운영 GPU/Metal 엔진 변경 없음.**
