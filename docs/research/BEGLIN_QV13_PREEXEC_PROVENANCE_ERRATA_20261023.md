## 3. 과학적 판정과 재현 지침

Qv13은 실제 C 엔진의 고정된 마스크에 대한 유효한 비교 관측을 축적하지만, 위 사전등록 문구 차이로 인해 **문자 그대로의 사전등록 일치(pre-registration exact match)라고 표현하지 않는다**. 특히 파일럿 16문항은 통계적으로 탐색적이고 이미 부분 결과를 관측했다. 추후 별도 독립확증을 주장하려면 실제 코드 버전·역할 추첨 순서·정렬 해시 수식·마스크 SHA와 입력 SHA가 완전히 일치하는 **새 사전봉인 계약 및 새 독립 문항**에서 재시험해야 한다.

이 파일은 provenance에 관한 후행 정정 기록이다. 원래 prelock·masked source·개별 평가 로그·원본 모델 가중치·운영 릴리스·원본 커널은 변경하지 않는다.
