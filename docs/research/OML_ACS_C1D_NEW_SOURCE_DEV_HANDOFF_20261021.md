## 2. 실제 입력 조건부 게이트

이전 C1 고정 OOF co-error 모델을 확장했다. 한 문항 `x`에 대해:

1. 타깃을 제외한 두 소스 모델에서 최종 토큰 post-block BF16 활성값 `h_A(x), h_B(x)` 추출.
2. 소스별 같은 300 앵커로 `Ahat @ unit(h-mu)`를 구하고, 이 **300차원 소스 표현 두 개를 각각 단위화**한다.
3. 소스 TRAIN 200개 각 행에서 미리 계산된 같은 표현과의 cosine 유사도를 모델별로 구해 평균한다. 원본 행 순서로 안정적인 동점 결정을 적용해 **유사 문항 32개(top-32)** 선택.
4. top-32 행에 저장된 두 소스의 **5-fold OOF 0/1 오류**에 대해 조건부 2×2 **오류 공발생 2차 모멘트** `E[e e^T]` 계산. 이것은 평균 제거한 오차 공분산이 아니다.
5. 이웃 국소 행렬 50%, 전체 200행의 전역 OOF 행렬 50%를 섞고 ridge `1e-6`을 적용한 비음수 simplex의 2소스 최적 가중치 `w_A(x), w_B(x)`를 닫힌형 수식으로 계산한다.
6. 미리 source train으로 정해진 두 방향 `c_A,c_B`를 `unit(w_A(x)*c_A+w_B(x)*c_B)`로 결합해 **타깃 모델의 점수를 계산**한다. 타깃 활성값과 타깃 dev **레이블은 게이트 산출 단계에 전달하지 않으며**, 뒤의 AUROC 계산에서만 사용한다.

대조군: **균등 0.5/0.5**, 전역 **고정 C1 소스 OOF co-error 가중**, 이번의 **입력별 top-32 shrinkage co-error 가중**. 단위시험에서 조건부 가중치가 입력에 따라 실제로 변하고, 잘못된 차원·레이블 누수 경로·비정상 simplex를 차단하는 계약을 검증했다. 이는 모델 사이 행동축 **라우팅**이며 BEGLIN 텐서별/레이어별 비트 동적 양자화는 아니다. 두 소스 추론이 필요하므로 속도·메모리 이득을 가정하지 않는다.

## 6. 연구 결론과 후속 우선순위

C1-D는 **입력마다 신뢰도 가중치를 실제로 변화시키는 기술 가능성**을 확인했으나, 새로운 출처에서도 정적 C1 대비 성능 개선을 입증하지 못했다. 작은 상승을 “완료된 동적 할당 우월성”으로 표현하지 않는다.

향후 핵심은 동일 데이터로 가중치를 반복 변경하는 것이 아니라 **BEGLIN 국소 동적 양자화 Q를 별도 실기기 검증**하는 것, 입력 조건부 게이트의 실제 추론 비용과 지연을 기록하는 것, 그리고 기존 V6 24건 사용 이력·독립 평가자료의 의미 오염·원자료 라이선스를 감사한 뒤 새로운 미사용 평가를 동결하는 것이다.
