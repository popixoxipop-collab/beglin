## 4. 실제 비동기 병렬 실행의 현행 경계

이 연구 브랜치의 별도 SHA 고정 Qv2 바이너리는 **진짜 pthread QKV / GateUp 독립 스레드 풀과 JOIN**을 사용해 전체 Qwen 모델에서 ON/OFF를 실행했다. 관련 증거 `docs/research/BEGLIN_QV2_SELECTIVE_ASYNC_NATIVE_ABBA_EVIDENCE_20261022.json`. 그러나 **이전 동결 정책에 대한 실제 전체 모델** 성능은 직렬 평균 **93.62ms**, 비동기 평균 **93.66ms**로 이득이 없었다. 여러 병렬 모드 중 GateUp 6스레드만 평균 약 **0.24% 이득**, 보수적 **5% 반복 개선 게이트 불통과**. 선택적 비동기·자동 승격은 계속 OFF다.

이번 **새 50ms 후보는 실제 전체 모델 비동기 실행을 하지 않았다**. 해당 후보에서 관찰된 역할0 단계 시간 차이를 28계층에 낙관적으로 단순 합하면 QKV 절감 약 **2.211ms**, GateUp 절감 약 **1.896ms**, 합계 **4.107ms/토큰**이다. 83.24ms 기준 **5% 이상의 전체 가속**에는 약 **3.964ms 이상**의 절감이 필요하므로, pthread JOIN·큐·캐시/코어 경합을 포함해 허용되는 **낙관적 여유는 약 0.143ms**에 불과하다. 이 수치는 실제 전체 모델의 엄밀한 상한이 아니라, **역할0 단위 실측을 낙관적으로 합한 설명용 추정**이다. 따라서 실제 전체 모델 비동기를 근거 없이 기본 활성화하지 않는다.
